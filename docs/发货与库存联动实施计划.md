# 发货与库存联动实施计划

目标：在现有500表模拟实例上新增全单发货事件，原子写入物流和按SKU聚合的库存流水，更新受影响的库存快照。遵循候选、质量门禁、预期父版本发布流程。

1. 扩展严格批次协议，发货只允许指定订单、仓库和日期；数量从已支付订单推导。
2. 校验订单、仓库地区、重复发货、日期及整个受影响期间的库存余额；失败整批回滚。
3. 来源对账验证物流和出库流水；发布门禁检查逐日余额与快照。
4. 单元测试覆盖历史扣减、未来透支、日期、地区和批次原子性。
5. 用上阶段两笔模拟订单验收重复接入、回滚重放、地区隔离以及备份恢复。

范围：全单一次性发货、本地区仓库、SKU级库存，不支持拆单、跨区调拨、仓位、批次、序列号库存及实物退货入库。退款仍为财务事件，不自动增加库存。支付状态保持原值，以物流事实判断是否发货。历史种子物流与库存原本独立生成，仅本阶段接入的新发货具备来源级物流出库对账，不宣称历史全量物流已经逐笔对账。
