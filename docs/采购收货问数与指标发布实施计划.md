# 采购收货问数与指标发布实施计划

1. 增加已收货数量指标：按收货日期、仓库统计数量，不把采购订购量、收货单数或金额当作收货数量。
2. 增加五个批准示例，覆盖全期、2026年3/6/8/9月；Python独立逐行聚合核验SQL结果。
3. 新增只更新指标目录的候选发布入口，业务库字节保持不变，保留全部业务来源血缘。先生成候选，完整门禁通过后按预期父版本发布。
4. 验证指标依赖最小化、区域收货隔离、销售/售后角色拒绝、SQL数值口径、真实模型和持久任务。
5. 验证只改目录的版本可备份恢复，恢复副本可校验来源并实际运行。

数据仍为自建模拟；本阶段不会新增采购或制造收货事件来发布指标。权限仍由持久身份和执行层区域视图约束。
