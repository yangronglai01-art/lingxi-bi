# 宁波鲍斯能源装备 · 数据仓库 Schema 说明

> 本文档是「宁波鲍斯能源装备智能问数平台（灵犀 Lingxi）」数据层的**权威 schema 说明**，
> 是后续 Text-to-SQL prompt、语义层与 BI 前端字段口径的唯一来源。
>
> 字段清单与 `src/schema.py` 保持同步（单一数据源）。

---

## 1. 模型总览

采用**星型模型**：3 张维度表 + 3 张事实表。

| 表名 | 类型 | 业务含义 | 粒度 |
| --- | --- | --- | --- |
| `dim_product` | 维度表 | 产品（6 款核心产品） | 每个产品一行 |
| `dim_region` | 维度表 | 销售区域（四大区） | 每个区域一行 |
| `dim_customer` | 维度表 | 客户（设备制造商/工业服务/经销商/出口） | 每个客户一行 |
| `fact_sales` | 事实表 | 销售明细 | 每日 × 产品 × 区域 × 客户 |
| `fact_quality` | 事实表 | 质量抽检 | 每日 × 产品（每条产线一行） |
| `fact_production` | 事实表 | 生产计划与达成 | 每日 × 产品（每条产线一行） |

**表间关系（外键）**：

```
dim_product ─┬─ fact_sales.product_id
             ├─ fact_quality.product_id
             └─ fact_production.product_id

dim_region  ─── fact_sales.region_id

dim_customer ── fact_sales.customer_id
```

时间范围：`2025-09-01 ~ 2026-08-31`（最近 12 个月，固定区间保证可复现）。
数据总量：约 2.4 万行（销售 19,954 + 质量 2,190 + 生产 2,190）。

## 3. 事实表字段说明

### 3.1 fact_sales — 销售事实表（约 2 万行）

| 字段 | 类型 | 说明 | 示例值 |
| --- | --- | --- | --- |
| `sale_date` | DATE | 销售日期 | 2026-03-15 |
| `product_id` | VARCHAR | 产品编码（外键→dim_product） | P001 |
| `region_id` | VARCHAR | 区域编码（外键→dim_region） | R001 |
| `customer_id` | VARCHAR | 客户编码（外键→dim_customer） | C001 |
| `quantity` | INTEGER | 销售数量（件） | 30 |
| `amount` | DECIMAL(12,2) | 销售额（元）= 数量 × 单价 | 204000.00 |
| `cost` | DECIMAL(12,2) | 销售成本（元） | 142800.00 |

**核心口径**：
- `amount = quantity × unit_price`（严格成立，已校验）；
- 毛利率 ≈ `1 - cost / amount`，各产品毛利率约 30%~42%。

### 3.2 fact_quality — 质量事实表（2,190 行）

| 字段 | 类型 | 说明 | 示例值 |
| --- | --- | --- | --- |
| `check_date` | DATE | 抽检日期 | 2026-03-15 |
| `product_id` | VARCHAR | 产品编码（外键→dim_product） | P006 |
| `line` | VARCHAR | 生产/检测产线（产线1/2/3） | 产线3 |
| `checked_count` | INTEGER | 抽检数量（件） | 300 |
| `defect_count` | INTEGER | 不合格数量（件） | 33 |

**核心口径**：缺陷率 = `defect_count / checked_count`（精密零部件全检，抽检量≈当日产量）。

### 3.3 fact_production — 生产事实表（2,190 行）

| 字段 | 类型 | 说明 | 示例值 |
| --- | --- | --- | --- |
| `prod_date` | DATE | 生产日期 | 2026-03-15 |
| `product_id` | VARCHAR | 产品编码（外键→dim_product） | P006 |
| `line` | VARCHAR | 生产产线（产线1/2/3） | 产线3 |
| `planned_qty` | INTEGER | 计划产量（件） | 300 |
| `actual_qty` | INTEGER | 实际产量（件） | 285 |
| `downtime_hours` | DECIMAL(6,2) | 停机时长（小时） | 2.50 |

**核心口径**：生产达成率 = `actual_qty / planned_qty`。

## 4. 内建数据特征（供 AI 洞察 / Text-to-SQL 演示）

数据在生成时即埋入了三类可被 AI 发现的业务特征：

### 4.1 时间趋势（增长 + 季节性）
- **整体增长**：销售额逐月温和增长约 +1.8%；
- **季节性**：11~12 月年末旺季（×1.12）、1 月年初备货（×1.05）、2 月春节低谷（×0.78）；
- 示例结论：「全年销售额整体增长，12 月为峰值，2 月因春节明显回落」。

### 4.2 区域差异
- 销量权重：华东 0.42 > 华南 0.28 > 华北 0.20 > 西南 0.10；
- 示例结论：「华东销售额（约 1.27 亿，占 42%）显著高于西南（约 0.30 亿，占 10%）」。

### 4.3 良率波动（质量异常）
- **精密齿轮轴(P006) 在产线3 于 2026-03 ~ 2026-05 缺陷率阶段性偏高**（约 11%，正常约 2.5%）；
- 同期产线3（P006）停机概率同步升高（与良率联动，暗示设备老化/工艺问题）；
- 示例结论：「2026 年 3~5 月产线3 精密齿轮轴缺陷率异常，由 ~2.5% 升至 ~11%」。

### 4.4 毛利关系
- 每笔订单 `cost = amount × (1 - 毛利率)`，毛利率在基准值 ±4% 内浮动；
- 支持按产品/区域/客户/月份分析毛利与毛利率结构。

## 5. 数据生成方式与可复现性

- 随机种子固定为 `20240916`（`src/config.py` 中 `RANDOM_SEED`）；
- 所有随机性均来自该种子派生的 `random.Random` 实例，**任何机器任何时间运行产出完全一致**；
- 生成脚本：`python scripts/build_all.py`（生成 CSV 快照 → 建 DuckDB 数仓 → 灌数 → 校验）。
