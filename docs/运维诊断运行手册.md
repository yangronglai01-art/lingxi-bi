# 运维诊断运行手册

本地模拟工作台已提供只读运维快照；数据仍为自建模拟，不是小佩内部系统。没有新增业务数据、付费模型调用或外部通知。

## 页面与接口

通过 `python scripts/start_simulated.py` 启动，使用全局分析账号登录。在“运维诊断”展开区域点击“读取运维快照”，显示排队、运行、本次守护重启次数及运行失败样本，并展示心跳、告警、结果分类和成功任务耗时。

页面按需读取，不自动刷新。UTC采集时间和数据版本会随快照显示，数据版本变化会提示重读；即使版本未变化，队列也可能已经变化，应以采集时间理解快照。

接口为 `GET /ops/health?window_minutes=15`，需要持久员工凭据，时间窗范围1至1440分钟。仅role=analyst、无地区限制的全局账号可读。区域分析、销售、售后、仓储、基础查看账号被拒绝；页面也不为他们显示运维入口。原有个人任务列表权限保持不变。

## 读取内容

- 当前数据版本、身份和快照文件可用性、发布日志状态、工作心跳及当前守护会话是否就绪。
- 全部任务按状态计数；queued+running为待处理量；最早排队时长、过期或缺失租约、单员工最大待处理量。
- 真实配额来源与提交逻辑共用：每员工20个、全局200个。不是每秒QPS限制。
- 本次守护阶段、心跳距今、累计重启次数和本次预算；人工模式明确标记manual，不沿用旧守护会话的次数。
- 时间窗内最多最新200个终态任务的分类、成功率和成功任务端到端耗时；总终态数超过200时标记truncated。
- 近期异常最多返回10个任务标识、状态、分类、更新时间；不返回业务问题、SQL、结果原文、原始异常、owner或启动会话标识。

## 统计口径

终态时间窗按任务updated落在采集时刻之前的指定范围筛选，未来时间戳及窗外记录不进入样本。任务本身的全局状态计数不受近期窗口限制。

运行成功率分母为成功、运行失败、error、timeout、not_ready及已完成但结果状态未知的样本。权限拒绝、澄清、不支持、中断、取消和被替代任务分别展示，不放进该分母。中断单独告警，不能将其理解为没有故障。零样本成功率和耗时返回NULL，不显示成0。

耗时是成功任务created至updated，包含排队和执行，非纯模型时延。仅使用有效非负耗时，返回样本数与最近秩P50/P95。所有分类与百分位最多代表最新200个样本，不能当作全量生产SLA、模型准确率或业务结果正确率。

## 本地提示规则

- 排队至少60秒：检查工作进程及慢查询，不要反复用新幂等键重复提交。
- 全局或任一员工待处理量达到对应配额80%：降低提交速率，结合429退避。
- 存在过期或缺失运行租约：检查工作进程恢复，已中断任务使用新键重提。
- 工作进程或本次守护尚未就绪：显示degraded，并与匿名 `/ready` 的就绪判断共用同一实现。
- 发布未完成、业务快照文件不可用或身份存储异常：显示unavailable；身份存储无法读取时接口安全返回503。
- 重启预算已用完、近期运行失败或中断：展示对应排查建议。

诊断HTTP200表示成功取得快照，不代表服务健康，必须读取status、ready及alerts。/ready仍用于探针，未就绪返回503。告警阈值为本地排查提示，不是SLA承诺，不自动修改任务、发布数据或发送通知。

## 当前边界

这是本地只读排查工具，不是全天候监控平台，没有外部告警、长期指标存储或自动修复。探针的文件和心跳检查不代替完整发布门禁、真实模型可用性或数据正确性验证。数据、日志和系统时钟异常仍需操作者排查；人工无守护模式只按心跳新鲜度判断，无法立即识别刚刚退出的进程。没有进行多机高可用或长期生产负载验收。
