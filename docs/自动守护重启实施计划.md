# 自动守护重启实施计划

1. 增加单机启动器锁与工作进程守护，按0.5、1、2秒退避，每次启动累计最多重启3次。
2. 就绪检查绑定本次启动会话和工作进程PID，重启等待期间返回503，防止沿用旧心跳误报就绪。
3. 写入守护状态和审计；超出重启次数或API/UI进程退出时停止本启动器拥有的全部子进程，保留失败原因。
4. 保留人工故障验收模式，上一轮人工启动脚本明确关闭自动守护；普通启动默认开启。
5. 单元测试覆盖退避、预算、会话心跳、退出清理；独立恢复副本实际杀运行中的冷工作进程，验证自动拉起、60秒租约自然过期、重新提交及最终清理。
6. 验证重复启动器被拒绝、重启预算耗尽停止、正常退出不产生重启，并更新完整回归、发布验证和备份恢复证据。

范围：本地进程退出后的守护恢复，不是Windows系统服务、开机自启、多机高可用或宿主机故障恢复；不自动重放中断任务，不新增付费模型调用。
