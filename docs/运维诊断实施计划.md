# 运维诊断实施计划

1. 抽取统一就绪检查，供匿名ready探针和受控运维诊断共用，保持启动会话/PID及心跳判断一致。
2. 新增仅全局分析账号可读的运维快照：队列、最长等待、过期租约、重启预算、近期任务结果分类和端到端耗时。
3. 明确区分问数成功、权限拒绝、澄清和执行失败；最近结果最多200个样本，显示时间窗和截断情况，不返回问题、SQL、业务结果、原始异常或凭据。
4. 工作台提供按需读取的运维诊断区域；区域分析、销售、售后、仓储和查看身份均不能访问。
5. 测试队列积压、过期租约、旧会话心跳、失败率分母、零样本、敏感内容不泄漏及界面权限。
6. 独立恢复副本验收真实API和工作进程：健康、重启503与诊断降级、恢复、正常业务问数；完成回归、发布验证和备份恢复。

范围：本地只读诊断和页面提示，不发送外部通知，不做自动修复或修改任务状态。队列阈值是运维提示，不是生产SLA。
