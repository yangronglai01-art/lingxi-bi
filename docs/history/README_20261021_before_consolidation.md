## 运行当前业务实例

```powershell
cd D:\projects\lingxi
.\.venv\Scripts\python.exe scripts/provision_simulated.py
.\.venv\Scripts\python.exe scripts/start_simulated.py
```

工作台：http://127.0.0.1:18501 ，API：http://127.0.0.1:18000/docs 。使用 `data/petkit500/simulated_credentials.json` 中相应模拟员工的凭据登录；不要提交或外传该文件。默认真实模型模式，沿用已有.env配置。离线验证需显式追加 `--mode demo`，仅支持批准的32个问题。

启动器管理API、工作台和持久任务执行器。退出后用户、任务、审计与结果保留。首次使用者需先安装项目依赖并构建数据，当前机器已完成。

## 本轮实际能力

- 4个固定模拟员工，部门/角色/地区授权、账号禁用、令牌轮换及授权版本。
- BM25+BGE-M3真实语义检索，506条1024维向量持久缓存，指标依赖与批准关系补全。
- 执行连接内区域视图：订单、退款、设备与售后明细继承地域约束。区域身份无法访问没有批准区域策略的表。
- SQLite持久问数队列、幂等提交、配额、后台领取、续租、中断恢复、取消和结果隔离。
- AST只读权限、观察窗/分母检查及30天指标输出单位契约。审计失败不发布受管员工结果。
- 就绪检查、运行审计、SQLite一致备份和独立目录恢复应用。

## 范围

当前为单机单工作进程的模拟业务应用；支持本地文件网关三类新增事件，尚非真实公司接口或通用CDC；区域隔离由应用执行层强制视图实现，没有声称数据库原生RLS。元数据为版本JSON，向量为本地矩阵，控制库为SQLite，没有部署pgvector、生产SSO或多实例高可用。500表目录不等于支持500表任意业务问题。

原6表项目和数据库保留，PROJECT_PROFILE=legacy可切回旧实现。早期临时演示启动器start_interview.py仍可用；当前模拟业务入口为start_simulated.py。真实模型调用可能产生费用，失败不静默降级。完整限制和运维流程见运行手册。
